# 성광교회 예배부 체크리스트 (SK Service)

성광교회 예배부 주일 및 절기 예배 준비와 현장 진행을 돕는 모바일 최적화 웹 애플리케이션입니다.

## 🌟 주요 기능

1. **실시간 체크리스트 관리**
   - 1부, 2부, 오후, 특별새벽기도 예배 구분 지원
   - 구글 스프레드시트 연동을 통한 실시간 작업 목록 동기화
   - 순서코드별 분류, 검색 및 접기/펼치기 기능
   - 남은 항목만 모아보기 스위치 제공

2. **현장 사진 촬영 및 첨부**
   - 각 체크리스트 항목별 현장 확인 사진 촬영(카메라 바로 실행) 및 앨범 첨부
   - 사진 자동 리사이징 및 압축을 통한 최적화
   - 브라우저 로컬(IndexedDB) 무제한 안전 보관 및 전체화면 뷰어

3. **출석 인원 계수기**
   - 1부 / 2부 / 오후 예배별 남자, 여자(방송실, 성가대 포함), 인터넷 예배 인원 카운터
   - 한 번의 클릭으로 전체 출석 요약 내역 클립보드 복사
   - 출석체크 완료 시 `날짜-x부예배.txt` 파일을 구글 드라이브에 기록 (미연동·실패 시 기기에 저장)

4. **구글 드라이브 (`\예배부 데이터`) 자동 연동**
   - **사진 데이터**: `\예배부 데이터\사진` 폴더에 자동 분류 저장
   - **출석 집계표**: `\예배부 데이터\출석` 폴더에 텍스트 파일 자동 분류 저장
   - Google Apps Script 기반의 간편하고 안정적인 웹 앱 연동 지원

5. **모바일 퍼스트 UX**
   - 단일 파일 HTML 기반의 초경량 구조
   - 다크 모드 / 라이트 모드 지원
   - 스마트폰 한 손 조작에 최적화된 하단 독(Bottom Dock) 네비게이션
